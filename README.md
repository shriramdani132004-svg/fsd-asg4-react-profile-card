# Assignment 4 - React Profile Card Using Props

A React profile card created using a reusable component and props.

## Props Used

The `ProfileCard` component receives:

- `name`
- `imageUrl`
- `description`

## Technologies

- React
- Vite
- JavaScript
- CSS

## Component

`ProfileCard.jsx` is a reusable React component that receives the profile information through props and renders it dynamically.
